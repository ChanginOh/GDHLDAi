# Gradient Descent-Based Multiclass Harmonic Linear Discriminant Analysis (GDHLDAi)

An improved implementation of Riemannian gradient descent-based multiclass harmonic linear discriminant analysis for supervised dimensionality reduction. GDHLDAi optimizes an orthonormal projection matrix on the Stiefel manifold to identify low-dimensional coordinates that enhance class separation.
